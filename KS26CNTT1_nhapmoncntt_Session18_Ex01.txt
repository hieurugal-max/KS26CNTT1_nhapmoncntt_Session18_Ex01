Bài 1: Sự cố không truy cập được hệ thống quản trị
Phần 1. Phân tích
1. Xác định Input và Output
- Input: Tên miền phong-dieu-phoi.grenlog.vn.
- Output: Địa chỉ IP của máy chủ tương ứng.
2. Quá trình DNS Lookup

Khi Nam nhập tên miền vào trình duyệt, hệ thống thực hiện các bước:
- Bước 1: Trình duyệt kiểm tra DNS Cache.
- Bước 2: Nếu chưa có IP, máy tính gửi yêu cầu đến DNS Resolver.
- Bước 3: DNS Resolver tìm kiếm thông tin qua Root DNS Server, TLD DNS Server và Authoritative DNS Server.
- Bước 4: DNS trả địa chỉ IP về máy tính.
- Bước 5: Trình duyệt sử dụng IP để kết nối với máy chủ.
Sơ đồ DNS:
Tên miền (Input)->DNS Cache->DNS Resolver->Root DNS → TLD DNS →Authoritative DNS->Địa chỉ IP (Output)

3. Nguyên nhân lỗi

Nam nhập sai grenlog.vn thay vì greenlog.vn (thiếu chữ e).

Do tên miền không chính xác nên DNS không tìm thấy địa chỉ IP tương ứng và trả về lỗi DNS_PROBE_FINISHED_NXDOMAIN. Vì vậy, trình duyệt chưa thể kết nối đến máy chủ. Chưa có căn cứ để kết luận máy chủ công ty bị sập.
Phần 2. Triển khai
Quy trình kiểm tra HTTP Status Code
- Bước 1: Nhập lại đúng tên miền phong-dieu-phoi.greenlog.vn.
- Bước 2: Mở CMD và nhập lệnh nslookup phong-dieu-phoi.greenlog.vn để kiểm tra địa chỉ IP.
- Bước 3: Nếu phân giải được IP, truy cập trang quản trị.
- Bước 4: Nhấn F12, chọn tab Network và tải lại trang.
- Bước 5: Kiểm tra mã trạng thái HTTP trong cột Status.
Phân biệt hai lỗi:
- DNS_PROBE_FINISHED_NXDOMAIN: Không tìm thấy tên miền, chưa kết nối được đến máy chủ web.
- 500 Internal Server Error: Yêu cầu đã đến máy chủ nhưng máy chủ gặp lỗi khi xử lý.
Phần 3. Kiểm thử
Nếu Nam nhập đúng tên miền nhưng nhận mã 404 Not Found thì có nghĩa là:
- Tên miền đã phân giải được thành địa chỉ IP.
- Yêu cầu đã đến máy chủ.
- Máy chủ không tìm thấy trang hoặc tài nguyên được yêu cầu.
Nguyên nhân: Đường dẫn truy cập bị sai, trang quản trị đã bị xóa hoặc chưa được cấu hình.

Cách xử lý: Kiểm tra lại URL, xác nhận trang quản trị còn tồn tại và kiểm tra cấu hình đường dẫn trên máy chủ.
